cdj-flacwards

FLAC playback for the Pioneer DJ CDJ-900 (firmware 4.32). This page makes the update file from your own copy of the official firmware.

Warning: This patch changes the firmware of your player. A firmware update can make a player unusable, and a modified firmware can void its warranty. You use it at your own risk. There is no warranty.

1. Get the official firmware

Download CDJ-900v432.zip (firmware 4.32) from the AlphaTheta support site.

2. Select it here

This browser is too old. Use Chrome or Edge 103, Firefox 114, Safari 16.4, or a later version.

    3. Download

    Patched update Rollback update

    4. Install

    1. Save the rollback firmware, in-case you need to revert the patched `flacwards` firmware.
    2. Format a USB stick as FAT32. You can use an existing FAT32 stick without formatting it.
    3. Copy only C900MAIN.UPD from the patched zip to the root of that stick.
    4. Turn off the player.
    5. Hold [RELOOP/EXIT] and [USB], and turn on the power. Put the stick in the player when prompted. The player updates its firmware.
    6. When the update is complete, turn the player off and on.

    To go back to the stock firmware, install the rollback stick in the same way. The player then reports 4.32.
